# Sidebar 2.3.2

随手工作台：搜索、便签、窗口、计时器、系统与最近文件，支持卡片收展、置顶、排序和专注模式。

## 便签怎么用

- 默认读取 ~/Documents/notes 中的普通 Markdown 文件；目录可在插件设置中修改。点击“新建”创建空便签，不覆盖已有文件。
- 点开就是正文编辑框。停止输入约 800 ms 自动保存，也可手动保存。返回列表、新建、打开外部编辑器前，先等当前输入保存完成；保存期间继续输入也会排队保存。
- 关闭再打开侧栏时使用最新草稿，不用旧缓存覆盖输入。出现外部修改冲突时保留输入、停止覆盖，并提供“将当前输入另存为新便签”。
- 在正文写 - [ ] 事项，下方即可勾选或开始 25 分钟任务专注。支持 LF、CRLF、CR 及混合换行的任务定位；勾选只修改目标复选框。
- 到点不会自动勾选任务。已有计时不会被新任务替换，暂停和加时保留任务关联。

## 计时与卡片

- 时长支持 90s、25m、1h30m、1:30（分:秒）、1:30:00、中文单位；裸数字按分钟解释，范围 1 秒至 24 小时。
- “常用”展开搜索；“专注”只留当前卡，退出时恢复原布局；“收起”折叠全部卡片。右上角可整理顺序和置顶。
- 搜索用 Alt+↑/↓ 选择、Enter 打开；普通方向键留给文本编辑。
- 以下计时快捷命令在侧栏关闭时也会处理，不会强制打开面板：

~~~sh
noctalia msg plugin pang/sidebar:panel all timer start:25m
noctalia msg plugin pang/sidebar:panel all timer stop
noctalia msg plugin pang/sidebar:panel all timer reset
noctalia msg plugin pang/sidebar:panel all timer extend:300
~~~

## 数据安全与已知边界

- 正文编辑上限 64 KiB；更大的便签交给外部编辑器。任务扫描每份最大 256 KiB，显示前 100 项；目录不递归，最多扫描 2000 个目录项、列出 100 份便签。
- 拒绝路径穿越、符号链接和硬链接写入。正文先写完整临时文件，核验版本后原子替换；保留权限、UTF-8 BOM 和 CRLF 风格。不因测试删除、迁移或改写原便签。
- 提交后的回读必须与本次内容相符，不能把外部编辑结果当作自己的保存回执。外部编辑器不一定遵守目录锁，最后核验与写入之间仍有很小的并发窗口，尽量不要同时编辑同一文件。
- “未保存”或“冲突”内容请先另存或复制，尤其在退出、禁用、更新插件或重启 Noctalia 前；不要把内存草稿当成已落盘的备份。
- 后台计时跨侧栏关闭继续运行；热重载后可接管，但剩余时长未知时只显示“后台计时中”，不提供加时。
- Noctalia 5.2.1 的原生文本框冒号混排问题不在本轮修改范围；本轮没有安装宿主补丁。

## 验证与恢复

从仓库根运行统一入口：

~~~sh
bash sidebar/tests/run_all.sh
~~~

目前共 106 项检查：10 项基础、14 项原有回归、11 项异步、24 项编辑器/任务界面、13 项使用边界、30 项文件与保存、1 项扫描脚本、3 项后台计时协议。文件写入只在测试自建临时目录，通知使用替身，不操作用户计时器。另运行宿主静态检查和工作量基准；基准不是实机帧率。

本轮前的源码快照：[修复前快照](<../.backups/sidebar-before-ux-audit-6d91251f.tar.gz>)。已有历史备份保留在 [本地备份目录](<../.backups/>)，不入库。恢复时只还原需要的源码，不要覆盖当前运行数据或便签。

宿主直接读取这个目录。源码更新后会热重载侧栏；没有生效时才考虑手动重新启用，操作前先处理未保存输入：

~~~sh
noctalia msg plugins disable pang/sidebar && noctalia msg plugins enable pang/sidebar
~~~
