# mpv 使用说明（arch-noctalia 配置）

配置都在这个目录里：`~/.config/mpv/`
- `mpv.conf` —— 主配置（顶部有这份说明的简版，改配置看它）
- `input.conf` —— 键位
- `script-opts/` —— uosc 主题、assrt 字幕配置（含 token，权限 600）
- `scripts/` —— 弹幕脚本 bdanmaku、字幕脚本 assrt

## 常用操作

| 键 | 作用 |
|---|---|
| **右键** | 功能菜单（字幕 / 音轨 / 清晰度 / 播放列表 / 章节 / 退出） |
| `SPACE` | 播放 / 暂停 |
| `f` | 全屏 |
| `q` / `Q` | 退出（`q` 记住播放进度） |
| `←` `→` | 快退 / 快进 5 秒（加 `Shift` 是 30 秒） |
| `↑` `↓` | 音量 |
| `[` `]` | 减速 / 加速，`BS` 复位 1.0 |
| `m` | 静音 |
| `s` | 截图到 `~/Pictures` |
| `?` | 查看全部键位（可直接打字搜索） |
| `Ctrl+o` | 打开文件 / URL |
| `Ctrl+l` | 挂外挂字幕 |
| `Ctrl+j` / `a` / `v` | 字幕 / 音轨 / 视频轨 |
| `Ctrl+p` | 播放列表 |
| `Ctrl+i` 或 `Ctrl+c` | 章节 |
| `Ctrl+q` | 清晰度（网络流） |
| `Ctrl+t` | 临时隐藏界面 |
| `Alt+f` | 在文件管理器里定位当前文件 |

## 进阶（都不用记）

- **B 站弹幕**：直接用 mpv 打开 B 站链接即可，弹幕自动出现；`v` 开关弹幕
- **在线字幕**：本地片没字幕时按 `a`，从 assrt.net 搜；选中后自动下载、改名成同名放在视频旁边（下次直接加载）
- **Anime4K 画质超分**：`Ctrl+1` / `Ctrl+2` / `Ctrl+3` = 1080p / 720p / 480p 动画模式，`Ctrl+0` 关闭（**默认关**，开了明显吃 GPU）

## 改配置时注意

mpv 里 `[名字]` 这一段是 profile，只有 `--profile=名字` 时才生效 —— **全局设置必须写在第一个 `[` 之前**（`mpv.conf` 现在就是这样的顺序）。
