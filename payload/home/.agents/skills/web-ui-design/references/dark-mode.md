# 暗色主题

暗色不是把颜色反转。本文件覆盖方向选择、表面层级、色彩与图像适配、切换机制与验收。

## 核心原则

- 降低整体亮度，减少眼疲劳
- 用更亮的表面表达层级（暗色下阴影不可见）
- 暗底上的高饱和色会振动，降饱和 10–20%
- 保持足够对比度以维持可读性（正文 ≥4.5:1）
- 只反转颜色不是暗色设计；要重新设计表面

## 先选暗色方向

依据品牌种子色、内容介质、环境光与使用时长，选择中性、暖偏、冷偏或品牌色调的暗色。**先检查现有 token**；没有证据时优先低彩度中性基线，不要默认暖色、蓝灰或纯黑。暖色、卡片、颗粒、辉光都不自动等于更高级。

## 表面层级

| 层 | 亮色模式 | 暗色模式 |
|-------|-----------|-----------|
| 页面背景 | `#ffffff` | `#0a0a0a`（不用 `#000`；分层时更"深"） |
| 卡片/表面 1 | `#f5f5f5` | `#171717` |
| 抬升表面 2 | `#e5e5e5` | `#262626` |
| 覆盖层 | `rgba(0,0,0,0.5)` | `rgba(0,0,0,0.7)` |

暗色四层参考：Background（最深，`#0a0a0a`/`#121212`）→ Surface 1（`#111`/`#1e1e1e`）→ Surface 2（`#1a1a1a`/`#2a2a2a`，模态与下拉）→ Surface 3（`#222`/`#333`，tooltip 与菜单）。

层间亮度差约 6–8%；**用边框而不是 box-shadow** 区分层级。层级可以用背景、分隔线、留白或重叠表达，不是所有东西都要做成卡片。

## 色彩适配

- 主色：降低饱和度 10–20%
- 错误/警告：为暗底重新调整对比
- 文字：用灰白（`#E0E0E0`/`#ededed`）而非纯白 `#FFFFFF`
- 边框：低不透明度白色，保持克制

```css
/* 语义 token 化，配合偏好媒体查询 */
:root {
  --bg-primary: #ffffff;
  --fg-primary: #171717;
}

@media (prefers-color-scheme: dark) {
  :root {
    --bg-primary: #0a0a0a;
    --fg-primary: #ededed;
  }
}
```

## 暖色暗调（可选方向）

适合品牌素材确实偏暖、图像与文字需要温和氛围的场景——**不天然更高级**。

```css
--bg: #0a0a0a;           /* 近黑，非 #000 */
--bg-elevated: #111;     /* 略亮的卡片表面 */
--text: #f0ede6;          /* 暖白，非 #fff */
--text-dim: #888880;     /* 带暖调的辅助灰 */
--accent: #d4a574;       /* 琥珀主色 */
```

- 所有中性色向主色相偏移（+0.005–0.015 chroma），绝不用纯灰
- 黑底用 `#0a0a0a` 而非 `#000`
- 白字用 `#f0ede6` 或 `#e8e4dc`
- 表面边缘用 1px 半透明白边（`rgba(255,255,255,0.04–0.06)`）而非阴影
- 颗粒或渐变只在品牌需要物理材质时使用；纯色背景同样可以很精致

暖色主色候选：

| 名称 | 值 | 氛围 |
|------|-------|------------|
| Amber | `#d4a574` | 温和高级，ACG/作品集 |
| Gold | `#c4954a` | 复古奢华 |
| Warm Orange | `#e8a060` | 有活力的创作 |
| Rose Gold | `#d4a0a0` | 细腻柔和 |

暖色暗调的表面层级：

```css
--bg: #0a0a0a;                    /* 最深背景 */
--bg-elevated: #111;              /* 表面 1：卡片 */
--bg-overlay: rgba(17,17,17,.95); /* 表面 2：模态（配 backdrop-filter: blur） */
--bg-tooltip: #1a1a1a;            /* 表面 3：tooltip */
```

更多暖暗美学与叙事组合见 `visual.md`。

## 图片与媒体

- 图片整体可略微压暗
- 提供暗色专用插画版本
- Logo 可能需要浅色版本
- 避免图像中出现大面积高亮区域

## 切换机制

```tsx
// 类名切换（兼容 Tailwind dark mode）
document.documentElement.classList.toggle("dark", isDark)

// 或用 ThemeProvider context 供组件访问
```

- 同时支持 `prefers-color-scheme` 自动与手动开关，不要只做其中一个
- 用语义 token 让切换近乎零成本，组件不感知主题
- 避免主题切换闪烁：首屏渲染前就确定主题（内联脚本或服务端注入），不要在 hydration 后再改
- 尊重 reduced-motion：切换过渡要克制，时长取决于平台与界面切换频率

## 暗色验收

- 逐个组件在暗色下检查，而不只看首页
- 在真实暗环境下测试（低亮度房间、夜间）
- 正文对比度 ≥4.5:1，UI 元件与边框 ≥3:1
- 屏幕阅读器能正确播报模式（模式切换不应造成困惑）
- 与明色模式一致地检查状态色、禁用态、图表色阶
- 暗色不是"高级风格"的捷径：不得用暗色 + 辉光 + 卡片掩盖信息结构问题

## 常见错误

| 错误 | 修复 |
|---------|-----|
| 组件里写裸 hex | 用语义 token |
| 暗色用纯黑/纯白 | 用 `#0a0a0a` / `#ededed` |
| 用阴影表达层级 | 用更亮的表面 + 边框 |
| 高饱和色直接照搬 | 降饱和 10–20% 后复核对比 |
| 只用自动或只用开关 | 两者都提供 |
| 切换时闪白 | 首屏前定主题 |
| 只在首页检查 | 每个组件、每个状态都查 |
