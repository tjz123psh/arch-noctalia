# 韧性：极端输入、失败与边界

只在对理想数据下成立的界面不算做完。真实用户会给出超长文本、空值、Emoji、RTL、几千条数据、断网、重复点击、无权限——这些都不是异常情况，是常态。

**触发时机**：新建或改版涉及数据展示、表单、列表、异步操作、权限、多语言时读本篇。它在第 3 段验收之前完成设计侧加固；具体取证矩阵仍在 `validation.md`。

## 极端输入

### 文本长度

| 情形 | 要求 |
|---|---|
| 超长单词/URL/无空格字符串 | 必须能断行，不能撑破容器 |
| 超长标题 | 在目标断点逐个测试，溢出就降 `clamp()` 上限或改写文案 |
| 极短/空值 | 不渲染空标签、空行、悬空分隔符；`—` 或明确占位 |
| 单字符 | 输入框、表格列宽、按钮不应塌陷 |
| 大量项 | 列表 1000+ 条用虚拟滚动或分页，不要一次渲染 |

```css
/* 单行截断 */      .truncate { overflow:hidden; text-overflow:ellipsis; white-space:nowrap }
/* 多行截断 */      .clamp-3 { display:-webkit-box; -webkit-line-clamp:3; -webkit-box-orient:vertical; overflow:hidden }
/* 允许断行 */      .wrap { overflow-wrap:anywhere; hyphens:auto }
/* flex 子项可收缩 */ .flex-item { min-width:0; overflow:hidden }
/* grid 子项可收缩 */ .grid-item { min-width:0; min-height:0 }
```

截断必须提供获取完整值的路径（`title` / tooltip / 展开），否则用户永远看不到全貌。

### 特殊字符

Emoji（可能 2–4 字节或双宽）、组合字符、重音符号、不同书写系统都要测。CJK 与 Emoji 的显示宽度会导致等宽对齐错位——涉及对齐的表格和列必须按**显示宽度**而非字符数计算。

数字与日期一律走 `Intl`，不要手写格式：

```javascript
new Intl.DateTimeFormat(locale).format(date)
new Intl.NumberFormat(locale, { style:'currency', currency }).format(v)
```

复数不要拼 `count !== 1 ? 's' : ''`，用 i18n 库处理复数规则（各语言规则不同）。RTL、逻辑属性、文本膨胀的完整清单见 `i18n-rtl.md`。

## 失败与恢复

### 网络与 API

每个状态码都要有明确的界面反应，不能只弹一句"出错了"：

| 状态 | 界面处理 |
|---|---|
| 400 | 展示字段级校验错误，定位到具体字段 |
| 401 | 引导重新登录，保留原有意图（登录后回到原处） |
| 403 | 说明为何无权限、如何获取；不要伪装成 404 若无此意图 |
| 404 | 说明对象不存在，给出返回或重建入口 |
| 429 | 说明限流与等待时间，禁用重复提交 |
| 5xx | 通用错误 + 重试 + 支持入口；不要暴露堆栈 |

统一要求：**说明发生了什么 → 提供可执行动作（重试/返回/联系）→ 保留用户已输入内容**。

超时、断网、慢网要分别处理：断网提供离线可用范围或明确不可用；慢网给出进度而非无限转圈；重试要防抖，避免放大故障。

### 并发与重复提交

- 提交中禁用按钮（不是隐藏），并给出进行中状态。
- 快速连点不得产生重复订单/重复创建。
- 乐观更新必须能回滚：失败时恢复原状并告知。
- 冲突解决要有明确策略（后写覆盖 / 提示用户选择），不要静默丢弃。

### 权限与降级

无权限查看、无权限编辑、只读模式是三种不同状态，文案与可操作项都不同。禁用项保持可读并说明原因。核心功能在 JS 未就绪或部分能力缺失时仍可用（渐进增强），不要整页白屏。

## 边界与大数据

- **加载**：区分首次加载、分页加载、刷新；说明在加载什么（"正在加载项目…"），长操作给进度或阶段。
- **空状态**：分成四类并分别设计——**首次使用**（讲价值 + 给模板入口）、**用户清空**（轻提示 + 易重建）、**无结果**（建议改查询或清除筛选）、**无权限/出错**（说明原因 + 恢复动作）。空状态是引导机会，不是留白。
- **大数据集**：分页或虚拟滚动，配搜索与筛选；不要把 10,000 条一次塞进 DOM。
- **资源卸载**：路由切换/组件卸载时清理监听器、订阅、定时器，取消未完成请求。

## 健壮性设计自检

改完之后，逐条问：

- 超长文本、空值、Emoji、CJK、RTL 会怎样？
- 断网、慢网、超时、5xx、429 会显示什么？
- 连点提交、并发操作、请求乱序返回时状态是否正确？
- 无权限、只读、部分数据到达时界面是否仍然可用？
- 1000 条数据、200% 缩放、无颜色模式下是否仍可完成任务？
- 每处失败是否都给了下一步动作，并保住了用户输入？
