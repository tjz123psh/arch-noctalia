# TUI 验收集与终端卫生参考

用真实终端条件与可复现证据验收，不接受单张宽屏截图。先读本文件，再按项目风险选组合。

## 功能场景

- 首次启动、无数据。
- 典型数据与超长标签。
- 空搜索与无结果。
- 可恢复错误与阻塞错误。
- 慢操作、进度、取消、重试。
- 选中激活期间数据刷新。
- 多选与破坏性操作。
- resize 期间帮助/命令覆盖层打开。

## 兼容性场景

- 本机常见终端模拟器。
- 相关时覆盖 tmux 或 screen。
- 色彩能力受限的 SSH。
- 支持时的非 UTF-8 或缺失字形回退。
- 用户可控的浅色与深色背景。

## 验收矩阵

| 维度 | 必测取值 |
|---|---|
| 宽度 | 60、80、120、160 列 |
| 高度 | 20、30、50 行 |
| 颜色 | TrueColor、256、16、`NO_COLOR` |
| 背景 | 浅色、深色 |
| 字符 | ASCII 回退、Unicode、宽字符 |
| 输入 | 方向键/Tab、惯例键、快速重复、Esc |
| 状态 | 空、加载、成功、错误、断连、长内容 |

## 证据优先级

1. 纯状态转移测试。
2. buffer/snapshot/golden 测试。
3. 伪终端自动输入测试。
4. 真实终端截图或录屏。
5. SSH/tmux/不同模拟器的代表性冒烟测试。

不得用只比较 ANSI 字符串的测试替代真实宽度与终端恢复检查。

## 任务路径

至少完整走通：启动 → 主任务 → 错误恢复 → 返回 → 退出。

检查：

- footer 提示与当前模式一致。
- Esc/返回路径稳定，焦点回到合理对象。
- 选中、滚动、输入内容在 resize 后保持。
- 快速输入不产生过期搜索结果或重复危险操作。
- 后台任务可见、可取消或明确不可取消。

## 屏幕审查

- 首要任务在每个尺寸都保持第一视觉优先级。
- 无无意义的嵌套边框、重复标题、卡片墙。
- 表格列按价值降级，不是随机丢掉最后一列。
- 文本截断有获取完整值的路径。
- 焦点、选中、错误、禁用即使无颜色也可区分。
- 内容更新不引起不必要的布局跳动或闪烁。

## 终端卫生

正常退出、错误退出、取消、panic 四条路径都要检查：

- raw mode 已关闭。
- alternate screen 已退出。
- 光标可见、echo 正常。
- 鼠标捕获已释放。
- 没有后台日志继续污染 shell。

## 性能

- 持续日志或高频指标下输入仍响应。
- 大列表使用虚拟化、窗口化或受控渲染。
- resize 风暴不引起无限重绘、任务泄漏或阻塞。
- 帧更新只重算必要区域或必要视图模型。

## 框架钩子

- **Ratatui**：`TestBackend` 与 `Buffer` 断言。
- **Textual**：Pilot 与 snapshot 测试。
- **Bubble Tea**：纯 `Update`/`View` 测试加伪终端冒烟测试。
- **Ink / OpenTUI**：使用框架自身文档给出的测试与帧捕获指引。

## 交付物

报告必须列出：测试矩阵、失败证据、已做修正、未覆盖环境、残余风险。不要只写"看起来没问题"。
